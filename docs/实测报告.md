# 板端实测报告

报告根据实际转换、板端输出与验收记录生成。三个模型独立运行，不把模型推理耗时当作整条链路帧率。

## 验收进度

最新NPU瓶颈定位与超分图优化已完成，详见[NPU第三轮报告](NPU瓶颈定位与第三轮优化.md)。下面保留原完整验收数据，当前版本未完成三项目长时间稳定性验收。

当前状态：**interrupted_reboot**。已记录 12 个测试项。

每个模型的规定验收为三轮各300秒和一次1800秒连续运行，另有调度扫描及阻塞测试。只有完整时长结束后才确认稳定性。

原验收在超分测试期间因开发板意外重启中断，用户确认没有操作开发板；原因尚未查明。当前已停止原后台验收，不会自动恢复高负载测试。

失败或中断原因：Unexpected board reboot during real_esrgan-repeat-2; user confirmed no manual action. Cause unproven.

自动交付未通过：RuntimeError('Qualification stopped or board restarted: running')。不能据此宣称最终验收通过。

## 性能目标与限制

初始目标是深度20FPS、超分256方形ROI约40ms纯推理、YOLO跟踪30FPS级处理。上述目标不由示例数字自动保证。最终以各项目recommended.json中的measured_fps、stability_validated与performance_target_met分别说明实测帧率、稳定性和性能达标情况。

深度与超分的INT8在当前校准配置下损失过大，按约定保留FP16；不得把INT8速度与FP16画质混成一个结果。NPU三核上下文增加吞吐也可能增加单帧耗时。模型、尺寸与画质优先，未达目标时保留实测瓶颈。

物理HDMI断连、光学端到端延迟、米制深度标定和科学成像任务精度不属于本次已通过的声明。注入显示异常与真实拔线不同。
